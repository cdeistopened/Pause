# Technical Stack

The entire content base for this project is written in **Markdown (`.md`)**.

There are no other programming languages, frameworks, or complex technologies involved in the creation and management of the content itself.

The workflow relies on standard text editors and file system organization.

The only "technology" in the broader sense is the plan to use a Large Language Model (LLM) for the companion app, but the development of that app is outside the scope of this content repository.
