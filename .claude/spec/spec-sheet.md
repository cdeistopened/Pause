1. What This App Does
Pause is a mindfulness app that helps you take a quick break anytime. Tap one button to do a short guided meditation, set an intention, and track your progress over time.

2. Core Features
- Instant Pause: Tapping the global pause button launches a short, in-app guided meditation, then lets you pick an intention from a curated menu. The app logs the session and can schedule a follow-up reminder—all via a custom implementation.
- Habit Insights: See streaks, session counts, total time, trends, milestones, and exportable reports. Personalized recommendations are generated with in-app analytics using a custom implementation.
- Intention Builder: Create and organize intention templates with categories and tags, then publish them to your pause menu for quick selection or automatic application after sessions. All logic and flows are implemented in-app with a custom implementation.

3. Tech Stack
- Framework: Expo (React Native) for iOS and Android
- Database: Convex
- Auth: Clerk
- Feature-Specific Providers: Custom implementation (guided meditation playback, intention engine, habit analytics, scheduling)

4. UI Design Style
Modern, clean, intuitive UI without being flashy.
